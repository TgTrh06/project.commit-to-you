# CV ứng tuyển vị trí trong tym cậu

Landing page tĩnh cho một chiếc “CV ứng tuyển người yêu”, sẵn sàng đăng bằng GitHub Pages.

## Chạy tại máy

Mở `index.html` bằng trình duyệt, hoặc chạy một static server bất kỳ trong thư mục dự án.

## Cá nhân hóa trước khi gửi

- Tên ứng viên hiện là Trịnh Thanh Tùng; đổi nội dung trong `index.html` nếu cần.
- Liên kết phản hồi hiện dẫn tới Facebook của Tùng; đổi URL trong `index.html` nếu cần.
- Điều chỉnh nội dung ngày tháng, câu chuyện, và lời nhắn để đúng với hai bạn.
